# Md Alamin Sk — Personal Portfolio

A fully static, responsive personal portfolio showcasing my projects, skills, and contact links. It uses HTML, CSS, and vanilla JavaScript and deploys on Vercel's free Hobby plan without a server, database, account system, or paid hosting dependency.

## Features

- About, skills, selected projects, and contact sections
- Responsive mobile navigation, reduced-motion support, and accessible project details dialog
- Project category filters, scroll progress, active-section navigation, reveal animations, and back-to-top control
- GitHub, LinkedIn, email, project repository, and live demo links
- Static contact form that opens the visitor's email app with the message filled in
- SEO metadata, Open Graph metadata, and favicon

## Tech stack

HTML · CSS · Vanilla JavaScript · Node.js build script · GitHub · Vercel

## Run and build locally

Requirements: Node.js 18 or later. There are no runtime or build dependencies to install.

```sh
npm run build
```

The build copies `index.html` and the static assets into `dist/`. Preview it with any static file server, for example:

```sh
npx serve dist
```

## Deploy to Vercel Hobby

1. Push this repository to GitHub.
2. In Vercel, choose **Add New → Project** and import `Ace0th/personal-portfolio`.
3. Keep the detected build command `npm run build` and output directory `dist`.
4. Deploy. No environment variables, database, server, or paid add-ons are required.

Every push to `main` can trigger a new deployment once the GitHub repository is connected.
